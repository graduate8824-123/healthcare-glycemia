# Limitations and safety

- No clinical validation, calibration study, prospective trial, or causal inference has been performed.
- Synthetic data exist only to prove technical operation. Their performance results must not be cited as health performance.
- HUPA-UCM schema, special values, licence, collection context, and population scope must be verified after lawful acquisition; this repository does not claim to have inspected unavailable raw files.
- Event labels depend on recorded future readings; missing sensor data can make outcomes unknowable.
- A 30-minute event classifier does not forecast a glucose trajectory.
- Random-forest feature importance is global model behaviour, not a clinical explanation or an individual causal reason.
- Model estimates are uncalibrated by default and must not be treated as absolute risk.
- No advice about insulin, carbohydrates, exercise, or treatment is generated.

Before any research use with real data, complete privacy review, governance approval, data licence verification, bias/fairness evaluation, external validation, calibration, clinical expert review, security controls, and applicable regulatory assessment.
